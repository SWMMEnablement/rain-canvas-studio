Rain Canvas Studio

Rain Canvas Studio is an interactive browser-based workspace for browsing, comparing, and referencing rainfall patterns used in hydrologic and hydraulic modeling. It functions as a rainfall pattern catalog, with a curated library that has grown past 265 documented patterns organized into tiers and covering multiple regions, including a set of Canadian patterns, alongside metadata and documentation for each pattern.

The app is aimed at storm selection workflows relevant to SWMM, InfoDrainage, InfoWorks, and related drainage modeling tools, helping engineers review available temporal distributions, compare patterns by region or tier, and pull reference storms into stormwater and drainage modeling studies. It is built with React, TypeScript, Tailwind CSS, and shadcn/ui, with a supabase folder providing backend and data-integration support for the pattern library.
