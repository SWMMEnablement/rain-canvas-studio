Rain Canvas Studio

Rain Canvas Studio is an interactive browser-based workspace for browsing, comparing, and referencing rainfall patterns used in hydrologic and hydraulic modeling. The app catalogue and public API list the same 339 distinct predefined storms across multiple regions, including Canadian patterns. Custom drawing is available separately and is not counted as a predefined storm. Both use one shared storm calculator; merged pattern aliases remain accepted in links and API requests.

The app is aimed at storm selection workflows relevant to SWMM, InfoDrainage, InfoWorks, and related drainage modeling tools, helping engineers review available temporal distributions, compare patterns by region or tier, and pull reference storms into stormwater and drainage modeling studies. It is built with React, TypeScript, Tailwind CSS, and shadcn/ui, with a supabase folder providing backend and data-integration support for the pattern library.
